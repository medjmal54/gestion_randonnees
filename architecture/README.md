# Architecture diagrams

Open `architecture.drawio` with [diagrams.net (draw.io)](https://app.diagrams.net/) (web or desktop).

Pages included:
- **C4 - Context**: actors (visitor/user, admin, API client) and external systems (SQL Server).
- **C4 - Container**: MVC UI, API controllers, services, domain/data access within the ASP.NET Core app.
- **Domain Model**: simplified EF Core entities and relationships (User, Hike, Bus, Participation, Favorite).

These are baseline diagrams for the current migration state; update them as the architecture evolves.
